CHAKA / HELP

支持与安装

连接网页和本地项目，使用你本机配置的 Codex 完成任务。

Chaka 浏览器扩展需配合 Chaka 桌面端使用。首发仅支持 Codex；模型服务可能联网处理任务并另行收费。发送前请阅读隐私政策。

使用前准备

  • Chrome 浏览器，以及与扩展版本匹配的 Chaka 桌面端。
  • 本机已安装、可正常使用的 Codex，以及有效的账户登录或模型服务配置。
  • 你有权使用的项目目录。首次体验建议选择不含敏感数据的示例项目。

安装与连接

以下步骤适用于正式发行入口提供后；不表示当前已开放商店下载。

  1. 安装扩展。从正式 Chrome Web Store 页面安装 Chaka 浏览器扩展，按引导固定工具栏入口。
  2. 安装 Chaka 桌面端。下载对应版本的 macOS 安装包，打开磁盘映像，将 Chaka 拖入“应用程序”并启动。按系统正常提示完成首开。
  3. 准备 Codex。按照 Codex 官方安装与登录说明完成配置，在 Chaka 桌面端中确认 Codex 可用。不要把账户密码或 API 密钥发给支持人员。
  4. 连接 Chrome。按 Chaka 桌面端的浏览器连接引导操作，在实际使用的 Chrome 个人资料中打开 Chaka 引导页，点击“重新检查”。等待本机连接就绪。
  5. 选择项目。在 Chaka 中选择项目目录，核对显示的项目名称，再打开普通 HTTP(S) 网页开始使用。

如果 macOS 提示安装包损坏、无法验证开发者或无法打开，请保留错误信息并联系支持。不要关闭系统安全保护来跳过安装检查。

第一次使用

  1. 在网页右下角打开 Chaka 的 Dock，确认连接状态和当前项目。
  2. 在新会话点击“拿来用”请求页面行动建议，或输入问题并点击“发送”。这些操作会把当前网页和所选上下文交给本机 Codex，内容可能继续发送至模型服务商。
  3. 需要图片时，明确添加图片或选区到对话，再点击“发送”。仅打开面板生成的页面预览截图不会自动作为附件发出。
  4. 审阅建议后再决定是否执行项目任务。行动可读取、修改文件、运行命令及访问网络，当前执行过程不会逐条请求确认；项目工作目录不提供操作系统级完全隔离。
  5. 在对话中查看结果。需要停止时点击取消；关闭面板、页面或标签页不一定终止已发送的任务。

连接与任务排查

提示未安装 Chaka 桌面端或找不到本机连接
确认 Chaka 桌面端已安装并正在运行；回到其浏览器连接引导，确认使用的是安装了 Chaka 浏览器扩展的 Chrome 个人资料，再在扩展引导页点击“重新检查”。只安装扩展还不能运行任务。
Codex 不可用或任务报错
先确认 Codex 自身可正常登录和运行，再检查账户额度、模型配置和网络。Chaka 首发不会自动改用其他 Agent。保留界面错误文字，联系支持时注明任务停在哪一步。
某些页面没有 Dock 或无法读取
请在普通 HTTP(S) 网页尝试，确认扩展已启用且该网站的浮层没有被关闭。浏览器内部页、商店页等受限制页面可能无法注入扩展内容。
想停止任务
在任务界面点击取消。关闭标签页与取消任务不同；取消不会撤销已写入项目的文件，也不能撤回模型服务商已经处理的数据。
删除后仍提示附件未清理
保持历史面板打开，确认 Chaka 桌面端连接可用，然后点击“重试附件清理”。对话可能已经删除，未回收图片仍可能留在本机；关闭面板后不会自动重试。

数据与删除

在扩展设置的“数据与隐私”中管理可选浏览记录。它默认关闭；“停止记录”只停止后续记录，“停止并删除浏览记录”同时清理该功能的本机记录。

这不会删除对话、手动浏览报告、图片、Reader 剪藏、项目文件或 Codex／模型服务商的数据。对话可在历史中删除，Reader 剪藏需单独删除；卸载扩展也不会自动清空 Chaka 桌面端与 Codex 文件。详情见保存期限与删除边界。
